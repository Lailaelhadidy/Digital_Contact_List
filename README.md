# Digital_Contact_List
Java console-based digital contact list using ArrayList and Binary Search Tree (BST) with CRUD operations and recursion.

## Features
- Add contacts
- Remove contacts
- Search contacts
- Update contact information
- Display contacts in sorted order
- Isolate contacts starting with 0100
- ArrayList implementation
- Binary Search Tree (BST) implementation

## Concepts Used
- Object-Oriented Programming (OOP)
- Recursion
- Binary Search Trees
- ArrayList
- CRUD Operations (Create, Read, Update, Delete)

## Technologies
- Java
- NetBeans
